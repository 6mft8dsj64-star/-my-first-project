## 기능

### 여행 계획
- **여행지 선택**: 지역(13개) → 나라(80개) → 도시(151곳, 대한민국 국내 7곳 포함) 3단계 선택, 이름 검색(한국어·영어·각 언어 나라 이름)
- **출발 공항·항공사**: 국제선 공항 8곳 + 국내선 공항 7곳. 직항 / 인천 이동 후 직항 / 경유 안내, 운항 항공사 표시, 같은 나라 다른 도시 직항 추천
- **여행지 정보**: 항공권 시세(최저·평균·성수기), 3성급 호텔 평균 1박, 추천·성수기 달력, 숙소가 가장 싼 달·비싼 달, 하루 생활비, 비자(한국 여권 기준)
- **계획 짜기**: 날짜·인원·항공권 가격·숙소·일자별 일정·생활비·기타 비용
  - **날짜 선택**: 큰 달력 창(출발일 → 귀국일 순서로 누르면 닫힘). 날마다 성수기(빨강)·추천(초록)·비수기(회색), 명절·연휴 점 표시, 선택 기간의 성수기 일수·이유
  - **성수기 기준**: 설·추석 연휴(2026~2028), 여름휴가철(7/20~8/20), 연말연시, 일본 골든위크·오봉·실버위크·연말연시, 중국 국경절, 중화권 춘절 + 여행지별 성수기 달 (`season.js`)
  - **숙소**: 1~2성급·3성급·4성급·5성급 평균 1박 요금(비수기·평소·성수기). 스카이스캐너 한국에 공개된 성급별 평균(2026년 11월 조사, 26개 도시 직접 조사 + 10개국 평균) 기반, 나머지는 같은 지역 조사 도시의 물가 비율로 추정하고 화면에 출처·추정 여부 표시 (`stay.js`). 묵는 밤마다 비수기 −20%, 성수기 +40% 적용
  - **일자별 일정**: 날마다 "시작~끝 시간 · 가고 싶은 곳/할 일 · 1인 금액"을 자유롭게 적는 줄, 줄 추가·삭제, 날짜별 합계, 시간 겹침·순서 오류 알림
  - **안전 · 외교부 여행경보**: 여행지 정보에 주요 도시 단계(경보 없음·1~4단계·특별여행주의보)와 뜻, 더 높은 단계 지역, 확인 날짜, 외교부 해외안전여행 링크. 위험한 나라는 나라·도시 카드에 경고 표시, 효율 제안에 경고. 확인 못 한 나라는 단계를 지어내지 않고 "확인 필요"로 표시 (`safety.js`)
  - **대한민국 국내 여행**: 서울·부산·제주·경주·강릉·여수·전주. 출발 공항이 같은 지역이면 교통비 없음, 국내선이 있으면 항공사 표시(확인 못 한 노선은 안내), 없으면 KTX 일반실 왕복 추정(2026년 9월 요금 인하 반영), 국내 여행 팁
  - **현지 생활비**: 여행 스타일(절약·보통·여유) 선택 + 내 하루 생활비 직접 입력(안 쓰면 식비+교통 추정치). 같은 스타일 여행자들이 **가장 많이 입력한 금액대**(평균 아님, 극단값 제외) 표시, "이 금액으로 계산" 버튼
- **총 경비**: 항목별 비중 그래프, 1인당 금액, 어제 환율 대비 변동
- **효율 제안**: 출발 요일, 성수기, 예약 타이밍, 숙소, 빈 날/빡빡한 날, 환율 타이밍, 가장 큰 지출
- **저장한 계획**: 저장 당시 가격 vs 오늘 환율 가격 비교
- **내가 기록한 가격**: 직접 입력한 항공권 가격을 노선별로 기록
- **여행자 공유 시세** 👥: 사용자들이 입력한 항공권 가격을 모아 "여행자들은 보통 얼마에 샀는지"(중간값·대부분 범위) 표시
  - 도시 카드, 여행지 정보, 항공권 가격 막대(파란 핀), 효율 제안에 표시 — 3명 이상 모인 노선만
  - 로그인 + "이름 없이 공유" 체크 시에만 저장, 한 사람은 노선마다 1개(다시 입력하면 덮어씀), 엉뚱한 값은 자동 제외
  - 같은 출발 공항 기록이 부족하면 전체 출발 공항 기준으로 표시

### 환율
- 출처 3곳(open.er-api.com, fawazahmed0 currency-api, frankfurter) 중 **가장 최신 값** 사용, 브라우저 캐시 사용 안 함
- 어제 대비 변동, 최근 30일 추이 그래프, "최근 한 달 중 싼 편/비싼 편"
- 30분마다, 그리고 앱으로 돌아왔을 때 10분이 지났으면 자동 갱신
- 모든 출처가 실패하면 기본 환율로 계산하고 화면에 안내

### 계정
- **첫 화면**: "나만의 여행 계획을 짜보세요" + [로그인하기] [로그인 없이 하기] + 기능 소개(항공권 시세·인기 숙소·관광지 비용·실시간 총 경비). PC는 넓게, 휴대폰은 2×2
- **로그인 창**: 사이트 위에 어두운 배경 + 가운데 창(LOGIN). ✕·바깥 클릭·Esc로 닫기, 구글·이메일 로그인, 회원가입·비밀번호 찾기, **로그인 유지** 체크(끄면 브라우저를 닫을 때 로그아웃)
- **로그인 없이 하기**: 계획은 이 탭에만 잠시 보관(브라우저를 닫으면 사라짐), "이 계획 저장하기"는 로그인 필요. 그 상태로 로그인하면 만들던 계획이 계정으로 옮겨짐
- 구글·이메일 로그인 (애플 로그인 버튼은 Apple 개발자 등록 후 켜기)
- 계정별 계획·저장 목록·가격 기록을 Firestore에 보관 → 어느 기기에서든 이어서 사용
- 로그인 직후 바로 사이트 화면으로 전환, 로그인했던 기기는 처음부터 첫 화면을 띄우지 않음, 로그아웃하면 첫 화면으로
- 회원 탈퇴(본인 확인 후 계정·데이터 즉시 삭제), 개인정보처리방침(`privacy.html`)

### 설정 (오른쪽 위 ⚙️)
- **테마**: 라이트 / 다크
- **언어 15개**: 한국어, English, 日本語, 简体中文, 繁體中文, Español, Français, Deutsch, Italiano, Português, Tiếng Việt, ไทย, Bahasa Indonesia, Türkçe, العربية — 처음 접속 시 브라우저 언어로 자동 선택
  - 화면 문구뿐 아니라 도시 144곳·명소·숙소·팁·비자·공항·비행시간까지 모든 언어로 번역
  - 아랍어는 화면 전체가 오른쪽→왼쪽(RTL)으로 바뀜
  - 개인정보처리방침: 한국어판(`privacy.html`, 공식) + 영어판(`privacy-en.html`), 한국어 외 언어는 영어판으로 연결
- **가격 표시 통화**: 원화·달러·엔·유로 등 60여 개, 실시간 환율로 모든 가격 변환
- **로그아웃** (로그인했을 때만 표시)

### 문의
- 위쪽 메뉴 "문의" / 맨 아래 "문의하기" — 오류 신고·불편한 점·기능 제안·정보 수정·기타
- 어떤 언어로든 작성 가능(오른쪽→왼쪽 언어 포함), 문의 화면도 14개 언어
- **관리자만** 읽을 수 있음: 관리자 계정으로 로그인하면 📥 문의함 표시 (처리 완료·삭제·번역 보기)

### 보안·스팸 방지
- Firestore 보안 규칙: 회원 데이터는 본인만, 문의 읽기는 관리자만, 공유 시세는 본인 노선 1개만·가격 범위 검사·10초 제한
- 문의는 **로그인한 사람만** 보낼 수 있음 + 형식·길이 검사
- 숨은 함정 칸·3초 규칙으로 봇 차단, 30초에 한 번 보내기 제한
- Firebase App Check (Fraud Defense / reCAPTCHA Enterprise) — reCAPTCHA를 불러올 수 없는 환경에서는 자동으로 건너뜀
- 사용자 입력은 화면에 표시할 때 코드로 실행되지 않게 처리
