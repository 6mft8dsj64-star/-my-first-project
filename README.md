# 트립메이트 ✈️ — 여행 계획 웹사이트

여행지 정보 확인 → 일정 짜기 → 총 경비 계산 → 절약 팁까지 한 페이지에서.

## 기능
- **여행지 선택**: 지역(13개) → 나라(79개) → 도시(145곳) 3단계 선택 + 이름 검색
- **출발지·항공사**: 국제선 공항 8곳, 국제 여객선 항구 2곳, 국내선 공항 7곳 출발 지원. 직항/배편/인천 이동/경유 안내와 운항 항공사 표시
- **여행지 정보**: 항공권 시세(최저/평균/성수기), 여행자들이 많이 고른 숙소(선호도 %), 추천·성수기 월, 하루 생활비
- **계획 짜기**: 날짜·인원·항공권 가격·숙소·일자별 관광지·생활비 수준·기타 비용
- **총 경비 자동 계산**: 오늘 환율로 원화 환산, 항목별 비중 그래프
- **실시간 환율**: 매번 최신 환율 조회, 어제 대비 변동, 최근 30일 추이, "지금 싼 편/비싼 편" 표시
- **저장한 계획**: 저장 당시 가격 vs 오늘 환율 가격 비교 (날이 지날수록 변동 확인)
- **효율 제안**: 출발 요일, 성수기, 예약 타이밍, 숙소, 일정 밀도, 환율 타이밍 분석

## 실행
`index.html`을 브라우저로 열면 됩니다. (설치 필요 없음)

환율: open.er-api.com, frankfurter.app (실패 시 기본 환율 사용)
※ 항공 노선·비자·항공권·숙소·관광지 가격과 선호도는 참고용 추정치입니다.
